# Vijaya Shilpa Shala – Official Website

A modern, responsive website developed for **Vijaya Shilpa Shala**, a traditional stone sculpture and temple architecture organization based in Karkala, Karnataka, India.

The website showcases the organization's rich artistic heritage, stone craftsmanship, temple architecture, completed projects, and team while providing visitors with an accessible platform to explore its work and get in touch.

**Live Website:** https://vijayashilpashala.com

---

## About the Project

Vijaya Shilpa Shala was established in 1964 by the renowned sculptor Shilpi K. Shamaraya Acharya in Karkala, Karnataka.

The objective of this project was to develop a professional digital presence that reflects the organization's craftsmanship, artistic excellence, and legacy in traditional Indian stone carving and temple architecture.

The website combines a modern, minimalist design with subtle visual elements inspired by stone textures and traditional craftsmanship.

---

## Key Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Home Page:** Introduction to the organization, its craftsmanship, and featured projects.
- **About Us:** This section features three dedicated pages: About the Company, Founder, and Our Leadership.
- **About Company:** Information about the organization's history, vision, and heritage.
- **Founder Profile:** Dedicated section highlighting the life and achievements of the founder.
- **Projects:** Showcases completed temple architecture and stone sculpture projects with detailed descriptions and image galleries.
- **Our Leadership:** The visionaries behind our legacy of excellence.
- **Shilpa Guru Project:** Govt. of India Project for Preserving heritage, nurturing the next generation of artisans.
- **Gallery:** Categorized image collections featuring temples, pillars, Tulsi Katte, and other stone craftsmanship.
- **Team Section:** Introduces the organization's leadership and team members.
- **Contact Form:** Allows visitors to send inquiries directly through EmailJS integration.
- **Navigation:** Smooth navigation between pages using React Router.
- **Visual Design:** Minimalist layouts, elegant typography, subtle animations, and a premium stone-inspired color palette.

## Deployment

The website is deployed using **Netlify** and connected to its custom domain.

Deployment involves:

1. Connecting the GitHub repository to Netlify.
2. Configuring the production build command (`npm run build`).
3. Setting the publish directory to `dist`.
4. Configuring the required EmailJS environment variables in Netlify.
5. Connecting the custom domain.
